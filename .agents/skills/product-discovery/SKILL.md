# Product Discovery for TOEIC App

Your job is to identify the most valuable feature to build next, focusing on the core learning loop: **Learn → Practice → Measure → Diagnose → Recommend → Practice**.

## 5 Core Questions to Answer Before Proposing a Feature:
1. **What is the learner trying to achieve?** (e.g., 450 → 600, 600 → 750)
2. **Where are they stuck?** (e.g., Part 2 too fast, Part 5 grammar errors, vocabulary retention)
3. **What data does the app have about the learner?** (e.g., accuracy, response time, mistake history, streak)
4. **How can this data become actionable feedback?** (Don't just say "7 wrong", say "Weakness: Relative Clauses. Recommended: 10 targeted questions")
5. **Does this feature ACTUALLY make the learner learn better?** (This is the ultimate filter)

## Prioritization Criteria
When evaluating feature candidates, score them based on:
- **Impact (1-5):** How much does this improve learning outcomes?
- **Effort (1-5):** How complex is it to implement?

## Output
Select the **ONE** best MVP feature that provides the highest learning value with the lowest effort. 

Output should include:
### Goal
What problem does this feature solve?
### The MVP Feature
Describe the core functionality.
### Why this?
Justify the choice based on Impact and Effort.
### Next Step
Provide a clear directive to transition to the `plan` skill to figure out HOW to build this feature.
